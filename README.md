## Daftar Tugas

### 📂 Tugas 1: Hukum Ohm

Sebuah aplikasi web perhitungan Hukum Ohm pada rangkaian seri sebagai alat hitung sekaligus media pembelajaran interaktif. Aplikasi ini dapat menghitung nilai kuat arus listik (I, miliAmpere atau mA) berdasarkan besar tegangan listrik (V, Volt) dan kuat hambatan listrik (R, Ohm). Dilengkapi dengan panel informasi yang menjelaskan teori dan cara penggunaan.

- **[Lihat Video Laporan](https://youtu.be/NgzFH425OC0)**

**Teknologi:** HTML, CSS, JavaScript<br>

### 📂 Tugas 2: Responsive UI

Sebuah website Kopi Nusantara dengan penerapan **responsivitas UI** yang menyesuaikan tampilan dan tata letak berdasarkan ukuran layar. Terdapat beberapa bagian pada website, yakni navigasi, halaman utama, informasi tentang Kopi Nusantara, menu kopi beserta rekomendasi, dan kontak. Responsive layout diterapkan menggunakan **CSS Grid, Flexbox, dan media query** agar website dapat digunakan pada perangkan mobile, tablet (kecil dan besar), dan dekstop.

- **[Lihat Kode](./Tugas_2/)**
